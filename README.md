# 婚纱礼服试穿与返店清点系统

管理礼服档案、尺码、试穿预约、搭配配件、出店单、返店检查、清洁状态与押金。
客户信息与照片均为演示数据。纯 Python 标准库实现（`http.server` + `sqlite3`），
零第三方依赖。

## 一条命令启动

```bash
./run.sh                # 生成预约/出店/返店/扣款样例并启动 http://127.0.0.1:8000
RESET=1 ./run.sh        # 重建全部演示数据后启动
PORT=8080 HOST=0.0.0.0 ./run.sh
```

等价手动步骤：`python3 -m app.demo --reset` 然后 `python3 -m app.server`。

跑测试：

```bash
./run_tests.sh          # 30 个用例，覆盖五类必需场景
```

## 六大页面

| 页面 | 内容 |
| --- | --- |
| `/gowns` 礼服档案 | 统一 4:3 封面比例；卡片底部固定尺码与预约状态 |
| `/calendar` 试穿日历 | 按日展示预约；新建预约、到店、迟到取消、临时换款、开单 |
| `/accessories` 搭配清单 | 配件套装按编号整体绑定、组成件清单、缺件冻结/补齐 |
| `/orders` 出店核验 | 出店单列表、开立出店单（尺寸调整 + 污渍/细节照片） |
| `/returns` 返店检查 | 逐项打勾布局；异常照片与扣款金额并排；清洁质检、追加复核 |
| `/deposits` 押金记录 | 收取/扣款/退款与模拟支付适配器流水 |

右上角「当前视角」可切换客户：选择具体客户后即进入客户隔离视图，
只能查看和操作本人资源；店员视角（默认）可见全部数据。

## 核心业务规则

- **预约锁定**：预约锁定具体礼服与试穿时段；同礼服时段重叠、已出店、
  清洁未完成均拒绝预约。写事务使用 `BEGIN IMMEDIATE` 串行化竞争判定，
  并发放下同一档期恰好一笔成功。
- **迟到取消 / 临时换款**：迟到取消记录迟到分钟并释放礼服；换款关闭原预约、
  另建新预约并留痕（`appointment_changes`）。
- **配件套装**：按编号绑定，组成件在出店时自动成为检查项；返店缺件则套装
  置为 `incomplete` 冻结，补齐后方可再次绑定。
- **出店核验**：记录尺寸调整与出店细节/污渍照片；同一礼服不能同时存在
  两张有效出店单。
- **返店检查**：逐项打勾（正常/污渍/破损/缺失/超时），异常必拍返店照；
  超过约定返店时间自动追加「超时返店」项。出店照与返店照按检查项**配对**，
  单边照片提示待配对。全部勾选后才能确认，确认即冻结结果，礼服进入清洁。
- **清洁**：首轮可判不合格（返工，礼服继续锁定、不可预约），合格后才释放。
- **押金**：扣款必须关联检查项与**返店异常照片**，校验照片归属、阶段与
  押金余额；扣款与结算均带幂等键，重复提交不重复入账。已结算只可
  **追加复核**，不能改原检查结论。

## 演示样例（`app.demo`）

- 林晚：试穿 BW-001 + AC-01 → 出店 → 超时 80 分钟返店，
  酒渍 / 勾丝 / 皇冠缺失 → 清洁首轮不合格、复检合格 →
  押金扣款 1300 元、退 1700 元 → 清洁合格后重新预约；
- 苏绮：迟到 35 分钟取消；BW-003 临时换款 BW-004 + AC-03；
- 周棠：BW-003 + AC-02 出店中，返店检查进行到一半（可继续勾选体验）。

## 数据存放

- SQLite：`data/bridal.sqlite3`（预约、出店、检查、清洁、押金、扣款、流水）
- 照片目录：`data/photos/`（演示为本地生成的 SVG，上传文件存
  `data/photos/orders/...`，可替换为真实照片，系统只认相对路径）
- 结算：进程内模拟适配器 `InProcessPaymentAdapter`，按幂等键去重，
  流水落 `payment_ledger` 表。

## 代码结构

```
app/
  db.py        建表与连接（外键、busy_timeout）
  services.py  领域服务 + 模拟支付适配器（全部业务规则与事务）
  seed.py      基础演示数据（客户/礼服/尺码/配件）
  demo.py      端到端业务样例生成
  photos.py    本地 SVG 照片生成
  templates.py 服务端渲染页面（黑白 / 玫瑰红 #B76E79 / 浅灰 #F2F0EF）
  server.py    零依赖 HTTP 服务、表单动作、文件上传、照片静态服务
tests/         预约竞争 / 配件完整性 / 照片配对 / 押金幂等 / 客户隔离
```
